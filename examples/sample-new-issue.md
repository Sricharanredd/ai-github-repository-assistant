
# Sample New GitHub Issue

## Title
[Bug]: Password reset email is not being delivered

## Description

### Problem
When users request a password reset, the application displays a success message, but the password reset email is not received.

### Steps to Reproduce

1. Open the login page.
2. Click on "Forgot Password".
3. Enter a registered email address.
4. Submit the password reset request.
5. Check the registered email inbox.

### Expected Behavior
The user should receive a password reset email containing a secure password reset link.

### Actual Behavior
The application displays a success message, but no password reset email arrives.

### Environment

- Application: Web Application
- Browser: Google Chrome
- Operating System: Windows 11

### Additional Information

- Issue occurs with multiple registered email addresses.
- Spam and junk folders have also been checked.
- The problem appears to affect the password recovery process.

The assistant should identify this as a bug, determine its priority and severity, summarize the problem, and suggest an appropriate response for the repository maintainer.
