
# Sample Duplicate GitHub Issue

## Incoming Issue

### Title
[Bug]: Users are not receiving password reset emails

### Description

When a user clicks the Forgot Password option and submits their registered email address, the application shows a successful request message.

However, the password reset email is never delivered to the user's inbox.

### Steps to Reproduce

1. Navigate to the login page.
2. Select Forgot Password.
3. Enter a registered email address.
4. Submit the request.
5. Check the email inbox.

### Expected Behavior
A password reset email should be delivered successfully.

### Actual Behavior
No password reset email is received.
